# Nest UX prototype

এটি অনুমোদিত প্রথম UX milestone; production app নয়।

চালানো: repository root থেকে `python3 -m http.server 3000 --bind 0.0.0.0 --directory prototype`।

অথবা `prototype/index.html` browser-এ খুলুন। External resources প্রয়োজন নেই।

- চারটি প্রধান tab এবং secondary screens কাজ করে।
- Demo habits toggle/add, নভেম্বর ২০২৬ calendar event add, widget add/remove, scripted AI widget action/undo, local message preview, file metadata preview ও theme toggle আছে।
- কোনো real AI, Bluetooth scan/send, original Calendar/Habit database, notification, cloud বা package installation সংযুক্ত নয়।
- Demo state memory-only; reload-এ reset।
- Branding Nest সাময়িক proposal।
- Existing www/, bridge/ এবং native source অপরিবর্তিত।
- পরবর্তী ধাপের আগে user-এর visual review ও অনুমোদন প্রয়োজন।
